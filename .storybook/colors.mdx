# Colors

Read straight from `app/globals.css` (and Tailwind's palette), so this page is always current. Components use only the utility names shown here, e.g. `bg-primary-blue` or `text-danger-fg`. The rules for where each color goes (CTAs, text on light and on navy, dark surfaces) are in [DESIGN.md section 2](https://github.com/sakolakembara/sakola-kembara-landing/blob/development/DESIGN.md#2-color).

## Brand

Each utility takes its value from a brand-named primitive in `:root` (`--catalina-blue`, `--sunglow`, …). Body text needs at least 4.5:1.

## Status

For errors, success, warnings and notices, instead of raw `red-*`, `green-*` or `amber-*`. Each status has a text color, a background and a border. The `Alert` atom uses them.
